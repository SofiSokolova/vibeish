# Hobby Buddies — план MVP

> Название рабочее. Здесь записаны решения, принятые при планировании; меняем документ вместе с продуктом.

## Идея

Приложение и сайт, чтобы найти компанию для хобби. Человек открывает ленту в своём городе и листает карточки с конкретными планами: «настольный теннис в субботу в 18:00, нужен ещё один человек». Свайп вправо — отклик с короткой запиской. Автор объявления выбирает, кого позвать, и для выбранных открывается общий чат.

Отличие от дейтинга: свайпаешь не людей, а планы. Чат появляется только после того, как автор принял человека, поэтому написать незнакомцу первым нельзя.

## Решения

| Тема | Решение |
|---|---|
| Платформы | Android и сайт из одного кода (Expo). iOS — когда появятся результаты |
| География | Технически сразу Эстония, Финляндия, Латвия (и Литва). Продвижение — город за городом: Таллинн → Хельсинки → Рига |
| Режим поездки | Можно выбрать другой город и даты и откликаться заранее: финны в Таллинне, туристы, переезд |
| Возраст | Только 18+. Подростковая версия — позже, с проверкой возраста и только групповыми активностями |
| Языки интерфейса | en (основной), et, ru, uk, fi, lv. Польский — позже. До запуска переводы проверяют носители |
| Языки общения | В профиле и объявлении указаны языки, на которых человек говорит; по ним есть фильтр |
| Формат встреч | 1:1 и группы. Размер группы задаётся в объявлении, у каждого хобби есть значение по умолчанию |
| Стоимость | Поле «бесплатно / скидываемся ~€X / платно €X» и фильтр. Деньги в MVP передаются вне приложения |
| Места | Часть объявления, отдельного каталога нет. При выборе места — подсказки из OpenStreetMap |
| Маяки интереса | «Хочу заниматься X в городе Y». Срабатывают, когда желающих набирается на минимальную группу хобби. Ещё присылают уведомления о новых объявлениях |
| Чат | Свой, с первой версии, пока только текст |
| Модерация | Объявления и профили проверяет ИИ до публикации, сообщения — сразу после отправки (грубое нарушение скрывается). Спорные случаи решает человек в админке. Есть жалобы и блокировки, админу приходят уведомления в Telegram. При скрытии или бане пользователь получает причину (требование DSA). В правилах честно написано, что чаты проверяет ИИ |
| «Только для девушек» | Позже, вместе с проверкой профилей, и бесплатно: безопасность не продаём |
| Уведомления | Android — пуши через Expo. Сайт — email о важных событиях, web push позже |

## Переводы

- Хобби и города хранятся по постоянному ключу (`table_tennis`, `tallinn`), а их названия — в файлах переводов `src/i18n/locales/*.json` (`category.table_tennis`).
- Ключ никогда не переименовываем, меняем только перевод.
- Тексты пушей и писем собираются на сервере на языке получателя из тех же файлов.
- Если понадобится добавлять хобби через админку без обновления приложения, переводы переедут в базу.

## Экраны MVP

Вкладки: Лента · Встречи · Создать · Чаты · Профиль.

| Экран | Что там |
|---|---|
| Вход и онбординг | Язык → вход (код на email или Google) → 18+ и правила → профиль: имя, фото, языки, хобби и уровень → город |
| Лента | Карточки: вправо — отклик с запиской, влево — пропустить. Фильтры: хобби, дата, бесплатно/платно, размер группы, язык, город (режим поездки) |
| Объявление | Описание, время, место на карте, свободные места, автор |
| Создание | Хобби → когда → где (карта и подсказки из OpenStreetMap) → сколько людей, стоимость, язык → описание |
| Встречи | Мои объявления и мои отклики; у объявления — кандидаты с записками и кнопки «принять / отклонить» |
| Чаты | У каждого объявления свой чат, принятые кандидаты попадают в него |
| Маяки | Хобби, город, удобное время |
| Профиль | Свой и чужой (пожаловаться, заблокировать). Настройки: язык, уведомления, удаление аккаунта |
| Админка (веб) | Жалобы, отметки ИИ, пользователи и баны, объявления |
| Сайт | Лендинг и публичная страница объявления по ссылке |

## Данные (Supabase / Postgres)

| Таблица | Что хранит |
|---|---|
| `profiles` | имя, фото, дата рождения, о себе, языки, язык интерфейса, город, роль, бан |
| `categories` | ключ хобби, размер группы по умолчанию, порядок, активность |
| `user_interests` | хобби пользователя и уровень |
| `cities` | ключ города, страна, координаты, часовой пояс |
| `listings` | автор, хобби, время, место (точка PostGIS), размер группы, стоимость, языки, статус модерации |
| `applications` | отклики: кто, на что, записка, статус |
| `swipes` | что человек уже пролистал |
| `chats`, `chat_members`, `messages` | чаты, участники, сообщения со статусом модерации |
| `beacons` | маяки интереса |
| `reports`, `blocks` | жалобы (с оценкой ИИ и решением админа) и блокировки |
| `push_tokens` | устройства для пушей |
| `osm_places` | столы и площадки из OpenStreetMap для подсказок |

Доступ к данным ограничен правилами Row Level Security.

| Неделя | Что делаем |

| 5 | Чаты, ИИ-модерация, жалобы и блокировки |
| 6 | Маяки, админка, правила и политика конфиденциальности |
| 7–8 | Сайт и ссылки на объявления, полировка. Закрытый тест в Google Play (12+ тестировщиков с Android, 14 дней) и бета на сайте |

## Расходы на старте

- Supabase Free: 500 МБ базы, 50 000 активных пользователей в месяц, 1 ГБ файлов, 200 одновременных подключений к Realtime. Проект засыпает после недели без активности. Pro — $25 в месяц.
- Expo Free: 15 сборок Android и 15 iOS в месяц, обновления «по воздуху» — до 1 000 активных пользователей.
- Google Play — $25 один раз; App Store — $99 в год (позже).
- ИИ-модерация: на Claude Haiku 5.5 — около $0.20 за 1 000 сообщений. Модель выберем по тестам.

## Открытые вопросы

- Финальное название, понятное по-английски. От него зависят идентификатор Android-приложения (после публикации в Google Play его не поменять), домен и иконка.
- Лицензия: в репозитории пока лежит MIT-лицензия шаблона Expo.
- Язык, выбранный в приложении, пока не сохраняется: будет храниться в профиле, когда появится вход.
